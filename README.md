# deki-lab Homebrew tap

Casks for the macOS apps of [deki-lab](https://github.com/deki-lab).

```sh
brew tap deki-lab/tap
brew trust deki-lab/tap   # Homebrew 7+: third-party taps must be trusted
brew install --cask deki-lab/tap/<cask>
```

| Cask | App |
|---|---|
| `kubeport` | [Kubeport](https://github.com/deki-lab/Kubeport): Kubernetes port-forwards from the macOS menu bar |

Each cask in `Casks/` is updated by its app's release workflow.
